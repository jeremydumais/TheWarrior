# Typewriter sound

`typewriter.wav` is a shortened, faded version of `blipUI1.wav` from
**5 Blip UI sound effects!** by FunnyDude:
https://opengameart.org/content/5-blip-ui-sound-effects

Source archive: https://opengameart.org/sites/default/files/blipuisfx.zip

License: CC0 1.0 Universal (https://creativecommons.org/publicdomain/zero/1.0/).
The author states that attribution is not required.

The sample was trimmed to 20 milliseconds, given a 2 millisecond fade-in and
an 8 millisecond fade-out, and exported as mono 44.1 kHz 16-bit PCM WAV.
It was then pitched down one octave and filtered with a 1.6 kHz low-pass
filter to soften the high frequencies. The final sample is 40 milliseconds long.
Playback volume is set to 25% in GLTextBox. Replace `typewriter.wav` to change
the dialogue sound without changing the code.
